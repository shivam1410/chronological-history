# Planning artifacts

How this project was specified and built, in the order the work happened.

| File | What it is |
|---|---|
| [prd.md](prd.md) | Goal, scope, non-goals, acceptance criteria, risks |
| [design.md](design.md) | Screens, states, interaction rules, accessibility notes |
| [spec.md](spec.md) | Data model, contracts, technical approach, decisions and alternatives |
| [tasks.md](tasks.md) | Phase-by-phase execution plan with validation for each slice |
| [execution.md](execution.md) | What actually happened: save points, proofs, defects found and fixed |
| [state.json](state.json) | Machine-readable build state |

Proposals, not yet built:

| File | What it is |
|---|---|
| [deep-time-animation.md](deep-time-animation.md) | A risograph-styled, procedurally drawn Earth that tracks the timeline window |

`spec.md` is the contract the code is written against; where the two disagree,
the spec has been wrong before and is corrected in place with the reasoning
attached, rather than quietly edited.
